Bioclimatic Comfort Analyzer

This web application is a Bioclimatic Comfort Analyzer based on the ASHRAE 55 standard. It fetches real-time meteorological data (temperature and relative humidity) for any city and country using the Open-Meteo API, or allows manual simulation via sliders. It dynamically visualizes the current condition on a psychrometric scatter plot alongside the ASHRAE comfort polygon, featuring auto-scaling axes, humidity-adjusted thermal boundaries, and real-time clothing recommendations ranging from heavy coats to light summer wear.

Developed by Marcos Alonso using Gemini AI (free version).
